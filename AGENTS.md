# Repository guidance for coding agents

Before modifying this repository, read `docs/ai-context/README.md` and the context page it routes to for your task. Use `docs/workflow.md` for the current end-to-end system flow, and consult engineering notes before changing an established architecture or security decision.

Preserve all existing committed and uncommitted changes. Keep unsupported and incomplete results distinct from pass, never fall back to host notebook execution, and do not serialize raw data or runtime fingerprint keys.
